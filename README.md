# ML Foundation

This repository contains my machine learning foundation projects, experiments, and implementations.

The goal of this repository is to strengthen my understanding of machine learning by combining:

## Projects

### 1. KNN Experimental Study

A detailed study of the K-Nearest Neighbors algorithm including:

- Feature scaling
- Effect of different K values
- Euclidean vs Manhattan distance
- KNN implementation from scratch
- Validation against scikit-learn
- Effect of irrelevant/noisy features
